# workshop-skills

Two skills from `trobanga-skills`, copied without their eval suites.

| Skill | What it does | Try it |
|---|---|---|
| `draft-issue` | Rewrites one issue as a short brief: headline, lede, details for the agent, and a "Done when" checklist. Files nothing. | `/workshop-skills:draft-issue <paste your issue>` |
| `grilling` | Interviews you about a plan, one question at a time, each with a recommended answer. Acts only after you approve the list of decisions. | `/workshop-skills:grilling` after the draft |

## Install

```
/plugin install workshop-skills --marketplace <owner>/<repo>
```
